Each visualization shows three images side-by-side:
- **Left**: Original CT slice (grayscale)
- **Middle**: Ground truth segmentation mask (white = vertebral body)
- **Right**: Model prediction (white = predicted vertebral body)

## TensorBoard Logs

When viewing in TensorBoard (`tensorboard --logdir ./logs`):

### Scalars Tab
- **Loss/train**: Training loss over epochs
- **Loss/val**: Validation loss over epochs
- **Dice/train**: Training Dice coefficient
- **Dice/val**: Validation Dice coefficient
- **IoU/train**: Training IoU score
- **IoU/val**: Validation IoU score
- **Accuracy/train**: Training accuracy
- **Accuracy/val**: Validation accuracy
- **Learning_rate**: Learning rate schedule

### Graphs Tab
- Model architecture visualization

## Example Workflow Output

```bash
# 1. Prepare data
$ python prepare_data.py --source_dir ./raw_data --output_dir ./data
Found 600 images
Split: 420 train, 90 val, 90 test
Dataset organized successfully in ./data

# 2. Train model
$ python train.py --model unet --data_dir ./data --epochs 100
...
Best validation Dice: 0.9234

# 3. Evaluate model
$ python evaluate.py --model unet --checkpoint ./checkpoints/unet_best.pth
...
Mean Dice: 0.9234 ± 0.0456

# 4. Run inference
$ python predict.py --model unet --checkpoint ./checkpoints/unet_best.pth \
    --input ./test.nii.gz --visualize
Prediction saved to ./test_prediction.png
Visualizations saved to ./visualizations
```

## File Size References

Typical file sizes:
- Model checkpoint: ~120-140 MB (UNet), ~140-160 MB (ResNet50-UNet)
- Training history plot: ~200-500 KB
- Prediction image: ~50-200 KB
- Evaluation JSON: ~1 KB
- TensorBoard logs: ~10-50 MB per training run

## Notes

- All metrics are computed on the test set unless otherwise specified
- Training times are for NVIDIA RTX 2080 Ti GPU with batch size 8
- Results may vary based on dataset, random initialization, and hardware
- Visualizations use matplotlib default styling
- Predictions are saved as PNG by default but support other formats
